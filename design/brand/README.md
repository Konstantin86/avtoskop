# Avtoskop brand

The mark is a magnifier with a car in its lens: "auto" plus "scope", searching for a car.

| File                      | Use                                                                                                                         |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `avtoskop-mark.svg`       | Master mark (64×64, rounded square). The site's header logo, tab icon and preview images are drawn from it.                 |
| `avtoskop-avatar-640.png` | Profile picture for the Telegram bot (@BotFather → Edit Bot → Edit Botpic), Instagram, Threads and X. Made for round crops. |

Colours: blue `#0057B7`, yellow `#FFD500` with an orange `#F59E0B` layer behind the magnifier, white car with navy `#0A2C5E` wheels. The wordmark is "Автоскоп" / "Avtoskop" in Fixel Display Bold.

Avoid crosshair or rifle-scope imagery, despite "скоп" in the name.
